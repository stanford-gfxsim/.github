# Stanford Graphics Simulation

A Stanford CS research group led by [Prof. Doug L. James](https://graphics.stanford.edu/~djames/), working on physics-based simulation, computer graphics, and computational sound.

- **Group page** (members, alumni): https://graphics.stanford.edu/~djames/group/
- **Publications**: https://graphics.stanford.edu/~djames/publications/
- **Videos**: https://www.youtube.com/channel/UCAA2LQH9dWETxJ0zr2qI9AQ
- **Contact**: djames@cs.stanford.edu

Code released with our papers lives in the repositories below. Each repository's own README documents its paper, build instructions, and license.
